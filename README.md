# Rotaşa Assessment Desk

SENG440 course project by Cem Özal and Sertaç Ataç: a browser game in which the player is an external assessor running an informal TMMi v2.0 assessment of the fictional company Rotaşa Technology. Playable in English and Turkish.

- [`simulation/`](simulation/): the game (static site, no build step). See [simulation/README.md](simulation/README.md) for running, testing and deploying.
- [`docs/decision-map.md`](docs/decision-map.md): decision map and expert path (deliverable D1).
- [`docs/research/`](docs/research/): source notes on TMMi Level 2, TAMAR and the lectures.

Deploy on Vercel with **Root Directory = `simulation`**.
